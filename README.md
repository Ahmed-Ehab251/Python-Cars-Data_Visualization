## 📌 Overview
This project performs **Exploratory Data Analysis (EDA)** and data visualization on a cars dataset using Python.  
The goal is to explore relationships between car specifications, performance, pricing, and fuel types.

---

## 🛠️ Tools Used
- <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/python/python-original.svg" width="22"/> Python
- 📊 Pandas
- 📉 Matplotlib
- 🎨 Seaborn

---

## 📂 Dataset
The dataset contains information about different car models including:
- 🏢 Company and car names  
- ⚙️ Engine type and capacity  
- 🐎 Horsepower  
- 🚀 Top speed  
- ⏱️ Acceleration performance (0–100 km/h)  
- 💰 Price  
- ⛽ Fuel type  
- 🪑 Seats  
- 🔧 Torque  

---

## 🧹 Data Cleaning & Preparation
- Loaded dataset using Pandas  
- Handled encoding issues (`latin1`)  
- Explored missing values and data structure using `.info()`

## 🔎 Key Insights
- 💎 Luxury brands dominate the top price range (e.g., Ferrari, Bugatti)  
- 📈 Strong positive correlation between horsepower and price  
- 🚀 Higher horsepower generally leads to higher top speed  
- ⛽ Petrol is the most common fuel type in the dataset  
- 📊 Performance metrics significantly influence car pricing
